# AI Tool Usage

## AI Coding Tools Used

AI coding assistants were used during the development of ParcelPilot.

## How AI Was Used

AI assistance was primarily used for:

- Streamlit UI development
- UI styling and CSS improvements
- Debugging Python errors
- Debugging Streamlit errors
- Improving application structure
- Generating documentation
- README preparation
- Troubleshooting deployment issues
- Reviewing implementation approaches

## Human Responsibility

AI-generated suggestions were reviewed, tested, and integrated manually.

Application behavior, tool workflows, customer-specific rules, and final implementation decisions were validated against the project requirements and provided ParcelPilot data.

AI tools were used as development assistance rather than as an autonomous decision-maker for the submitted application.
